forgotPassword() —> affiche le formulaire avec le champ email
sendResetLink() —> reçoit l'email, génère le token, envoie le mail
resetPassword(string $token) —> affiche le formulaire nouveau mot de passe
updatePassword(string $token) —> vérifie le token, met à jour le mot de passe, supprime le token
